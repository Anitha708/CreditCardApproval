# 💳 Credit Card Fraud Detection

## 📌 Project Overview

This project is a Machine Learning-based Credit Card Fraud Detection system designed to identify potentially fraudulent transactions.

The system uses historical transaction data to train classification models and integrates the trained model with a Streamlit web application. Users can enter transaction details through the interactive interface and receive a prediction indicating whether the transaction is likely to be **fraudulent or legitimate**.

The project demonstrates the practical application of Machine Learning, data preprocessing, and classification techniques in the financial domain.

## 🚀 Features

- 🔍 Credit card transaction fraud detection
- 🤖 Machine Learning-based classification
- 📊 Data preprocessing and analysis
- 🌲 Random Forest classification
- 📈 Logistic Regression classification
- 🖥️ Interactive Streamlit web application
- ⚡ Real-time prediction through user input
- 📁 Trained model saved using Joblib

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Logistic Regression
- Joblib
- Streamlit

## 📂 Project Files

- `app.py` – Streamlit application for fraud prediction
- `train_model.py` – Machine Learning model training code
- `model.pkl` – Trained Machine Learning model
- `creditcard.csv` – Transaction dataset
- `requirements.txt` – Required Python libraries

## 🔄 Project Workflow

1. Load the credit card transaction dataset.
2. Perform data preprocessing and cleaning.
3. Prepare the features and target variable.
4. Split the dataset into training and testing sets.
5. Train Machine Learning classification models.
6. Evaluate the trained model.
7. Save the trained model using Joblib.
8. Load the model in the Streamlit application.
9. Accept transaction details from the user.
10. Predict whether the transaction is potentially fraudulent or legitimate.

## 📊 Machine Learning Models

### Logistic Regression

Used as a classification model to establish a baseline for fraud detection.

### Random Forest

A Random Forest classifier is used to improve classification performance by combining multiple decision trees.

## 🎯 Expected Outcome

The trained Machine Learning model predicts whether a given credit card transaction is potentially **fraudulent or legitimate** based on the provided transaction features.

The project demonstrates how Machine Learning can be applied to financial transaction data to support automated fraud detection and help identify suspicious transactions.

> **Note:** This project is intended for educational purposes and demonstrates a Machine Learning approach to fraud detection. It should not be considered a production-ready financial fraud prevention system.
