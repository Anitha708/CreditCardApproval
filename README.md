# 💳 Credit Card Fraud Detection

## Project Overview

This project uses Machine Learning to detect potentially fraudulent credit card transactions. A trained classification model is integrated with a Streamlit web application to provide an interactive interface for fraud detection.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest
- Joblib
- Streamlit

## Project Files

- `app.py` – Streamlit application
- `train_model.py` – Model training code
- `model.pkl` – Trained machine learning model
- `creditcard.csv` – Dataset
- `requirements.txt` – Required Python libraries

Expected Outcome

After training on historical data, the model can predict whether a new applicant is likely to receive credit card approval. The system demonstrates how machine learning can be applied in the banking and financial sector to automate and optimize approval workflows.
